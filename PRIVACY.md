# Privacy implementation — RELEASE.1

Effective 1 August 2026. Product notice version 1.1.

Khadija's World requires no account and includes no advertising or analytics. Core play and familiar NPC replies remain local. Smarter replies are optional, grown-up controlled, moderated through the same-origin Cloudflare function, and limited by session and daily allowances. The project logging path records outcome categories and timing rather than chat text.

Cloud sync is optional. The browser encrypts the world before upload. D1 stores the encrypted envelope, revisions, and technical device identifiers; the raw sync code and readable world JSON are not uploaded. Local data can be reset in the game or removed through browser site-data controls. A connected cloud copy can be deleted from Grown-Up Controls.

The public notice is `public/privacy.html`. This document describes the implementation and is not a legal certification.
