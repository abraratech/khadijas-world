# Khadija's World — Project Charter

## Product promise

A warm, family-friendly digital dollhouse where players arrange rooms, dress characters, combine everyday objects and invent their own stories without combat or failure states.

## Technical promise

The project will be built in Babylon.js and remain playable on the designated minimum laptop:

- Intel 4th-generation CPU
- Intel HD 4400/4600-class graphics
- 8 GB RAM
- Current Chrome or Edge
- WebGL rendering
- 30 FPS target on the low preset

## Development rule

No visual target becomes a production promise until it has been reproduced and measured in the live Babylon.js benchmark.

## Release gates

Every milestone follows this order:

1. Scope is written.
2. The smallest playable release is built.
3. It is tested on the minimum machine.
4. Failures and compromises are documented.
5. The milestone is explicitly approved before the next one begins.

## Current milestone

**ART.1K — Visual Readability and Hero Procedural Cast Refinement**

The current release removes obsolete single-player selection UI, makes interactive objects identifiable from the dollhouse camera, and then refines the procedural family and world cast. The deeper prop-remodelling and interaction-animation pass remains scheduled for ART.1L.
