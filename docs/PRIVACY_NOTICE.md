# Plain-Language Product Privacy Notice

Version 1.0

Effective 24 July 2026

Khadija's World does not require an account and does not intentionally collect
personal information. Release 1 contains no advertising, analytics, behavioral
tracking, external AI, remote chat service, social login, payment system,
location tracking, microphone access, camera access, or contact access.

Game progress is stored locally in the player's browser. NPC conversations are
created by the game's bounded offline conversation system. Recent conversations,
structured memories, settings, and friendship progress stay inside the local
save. Players or grown-ups can disable typed messages, disable remembered
conversations, clear one NPC's memories, clear all NPC memories, export a save,
or import a trusted save.

Please do not enter real names, addresses, school details, passwords, phone
numbers, photographs, exact locations, or other personal information into NPC
chat. A reminder is shown the first time typed chat is used.

Clearing browser storage may remove progress. An exported save is a local JSON
file controlled by the person who downloads it; store it somewhere appropriate
and import only a trusted file.

The game makes no required remote request after its own production files have
loaded from the host. WAMP deployment serves all game files locally.

This is a plain-language product notice, not a claim of guaranteed legal
compliance. Support contact: pending.
