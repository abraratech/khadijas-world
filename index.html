Plain-Language Privacy Notice

No account, advertising, or analytics: ordinary play and neighborhood replies stay on this device. The game does not sell personal information.

Optional Smarter replies: only after a grown-up enables them, an unknown typed message and limited game context are sent to the same-origin Cloudflare function for moderation and a reply. Technical logs use result categories and timing; the project code does not intentionally log chat text.

Optional cloud saves: the browser encrypts the world before upload. Cloudflare D1 receives encrypted save data, a revision, and technical device identifiers. The raw sync code and readable world JSON are not uploaded.

Control and deletion: local progress can be reset or cleared from the browser. A connected cloud copy can be deleted from Grown-Up Controls. Keep sync codes private, and do not type real names, addresses, school details, passwords, or other personal information into chat.

Notice 1.1 — effective 1 August 2026. This describes the current product implementation and is not a legal certification.

Accessibility Statement

Khadija's World supports keyboard navigation, visible focus, larger interface text, stronger control contrast, gentle motion, instant dialogue, touch targets designed for mobile use, and safe-area handling for notched screens.

The title screen, menus, settings, chat, privacy controls, and recovery screens use semantic controls and focus management. The 3D play area has keyboard instructions and spoken status updates, but it is not yet a complete non-visual equivalent of every spatial activity.

Statement 1.0 — reviewed 1 August 2026.
