# Accessibility implementation — RELEASE.1

Reviewed 1 August 2026. Statement version 1.0.

Implemented paths include keyboard navigation, focus trapping and restoration, visible focus, screen-reader status announcements, reduced motion, larger interface text, stronger control contrast, instant dialogue, 44-pixel touch controls, safe-area insets, software-keyboard viewport measurement, and compact landscape layouts. First launch respects the operating system reduced-motion preference.

Known limitation: the free-form 3D play space does not yet provide a complete non-visual equivalent for every spatial activity. Public policy pages and the in-game statement disclose this directly.

The public statement is `public/accessibility.html`.
