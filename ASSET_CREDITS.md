items are generated at runtime from Babylon.js geometry authored in the project
source. They use no external mesh, image, font, or marketplace asset.

`public/assets/characters/khadija/outfits/` are project-generated color variants

## ART.1E runtime status

The Quaternius Ultimate Animated Character Pack remains recorded below for
license auditing and rollback, but its Brother and world-NPC models are no
longer active runtime visuals. ART.1E uses original project-code procedural
geometry for those characters. Khadija is now the only active external GLB
character asset.

## ART.1K-A Ultimate House Interior Pack

The project owner supplied 123 separate Blend files from the Quaternius
**Ultimate House Interior Pack**. Twenty selected files were exported to compact
GLB files with Blender 5.2 and validated. Fourteen unique models are active as
High-only visual shells across the home, bedroom, Sunny Café, and grocery; six
remain review-only and are never loaded.

The source Blend files use legacy material diffuse colors. The first GLB export
retained material names but omitted most base-color factors, so ART.1K-A applies
a project palette at runtime using those names. The original procedural objects
remain the interaction and Low-quality fallback authority.

License: CC0 1.0 Universal. Provenance and selected filenames are recorded in
`docs/ART1KA_SELECTIVE_INTERIORS.md` and `art/ASSET_MANIFEST.json`.

## Mama visual status

The project-owner Mama GLB remains archived in the repository but is inactive.
The runtime now uses the original hero-procedural `parent` rig on all quality
tiers because the GLB did not include a genuine idle/talk animation set.
